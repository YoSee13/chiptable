# צ׳יפטייבל

ניהול ערבי פוקר בין חברים: כניסות, ריביי, קניות לחבר׳ה, התחשבנות אוטומטית וטבלת מובילים.
האפליקציה רצה על GitHub Pages, עם כניסה ב-Google ושמירה ב-Firebase (פרויקט `chiptable-66de8`).
`firestore.rules` הם כללי האבטחה שפורסמו ב-Firebase (רק המארח כותב, השאר צופים).

## חצי־חצי (`split/`)

אפליקציה נפרדת לחלוקת הוצאות בין חברים: קבוצות, הוצאות (שווה בשווה / סכומים / חלקים), יתרות, סגירת חשבון במינימום העברות ותרשימים, עם צלילים ורטט.
הנתונים נשמרים במכשיר בלבד (localStorage) עם גיבוי ושחזור לקובץ. כתובת: `/split/` באתר ה-GitHub Pages.
