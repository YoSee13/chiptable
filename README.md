# צ׳יפטייבל

ניהול ערבי פוקר בין חברים: כניסות, ריביי, קניות לחבר׳ה, התחשבנות אוטומטית וטבלת מובילים.
האפליקציה רצה על GitHub Pages, עם כניסה ב-Google ושמירה ב-Firebase (פרויקט `chiptable-66de8`).
`firestore.rules` הם כללי האבטחה שפורסמו ב-Firebase (רק המארח כותב, השאר צופים).

## חצי־חצי (`split/`)

אפליקציה נפרדת לחלוקת הוצאות בין חברים: קבוצות, הוצאות (שווה בשווה / סכומים / חלקים), יתרות, סגירת חשבון במינימום העברות ותרשימים, עם צלילים ורטט.
כמה מטבעות בקבוצה אחת: לכל קבוצה מטבע ראשי שבו מחושבות היתרות, וכל הוצאה נשמרת במטבע שבו שולמה יחד עם שער ההמרה של אותו רגע (נמשך אוטומטית משירות שערים ציבורי, ואפשר להקליד ידנית).
קבוצה מקומית נשמרת במכשיר בלבד (localStorage) עם גיבוי ושחזור לקובץ. כתובת: `/split/` באתר ה-GitHub Pages.

סנכרון בענן: אחרי כניסה עם Google קבוצות נשמרות ב-Firestore (אוסף `splitGroups`, אותו פרויקט Firebase) ומתעדכנות בזמן אמת אצל כל החברים.
מצרפים חברים בקישור הזמנה; מי שמחזיק בקישור ומחובר יכול להצטרף ולערוך. הכללים ב-`firestore.rules` חייבים להיות מפורסמים ב-Firebase כדי שהסנכרון יעבוד.
